<h1> Вариант 9 - Этап 2 </h1>
Программа поддерживает до 6 аргументов:
<h4>–– Имя анализируемого пакета .</h4>
<h4>–– URL-адрес репозитория или путь к файлу тестового репозитория.</h4>
<h4>–– Режим работы с тестовым репозиторием.</h4>
<h4>–– Версия пакета.</h4>
<h4>–– Имя сгенерированного файла с изображением графа.</h4>
<h4>–– Режим вывода зависимостей в формате ASCII-дерева.</h4>
А также проверяет их на корректность значений:
<h4> –– true или false для режима работы с тестовым репозиторием и вывода зависимостей </h4>
<h4> –– l, last и - для обозначения последней версии </h4>
Реализована возможность получить прямые зависимости Apline Linux (apk) пакета заданной версии из заданного репозитория
